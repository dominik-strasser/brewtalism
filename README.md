# Brewtalism

**A Brutalist concrete enclosure for the Gaggia Classic EVO.**

Brewtalism is an experimental redesign of the Gaggia Classic EVO espresso machine, replacing its original metal housing with a custom concrete body.

Inspired by Brutalist architecture and blocky, geometric forms, the goal is to create a minimalist, monolithic espresso machine with a raw, industrial aesthetic.

## The Concept

The project combines 3D modeling, additive manufacturing, and concrete casting to create a functional enclosure.

The design process consists of three main stages:

1. **3D Modeling** — Design a geometric enclosure around the components of the Gaggia Classic EVO.
2. **Prototyping** — 3D print the enclosure to validate dimensions, fitment, and assembly.
3. **Concrete Casting** — Design and 3D print reusable molds to cast the final concrete components.

## Project Goals

- Create a distinctive, Brutalist-inspired concrete enclosure.
- Preserve the functionality of the original espresso machine.
- Use simple geometric forms suitable for 3D printing and concrete casting.
- Design molds that allow for reliable casting and demolding.
- Share the 3D models, mold designs, and build documentation.

## Safety

This project involves modifying a mains-powered espresso machine containing high-temperature and pressurized components.

Concrete is not a direct replacement for the original metal housing's electrical, structural, and thermal properties. Appropriate grounding, electrical insulation, heat management, ventilation, and component mounting must be independently verified before operating a modified machine.
